# 時序分位數預測做為長期投資進場規則：總體設計

- 日期：2026-11-17
- 狀態：**已定版**。使用者授權雲端代為決策（「該做的決策你幫我做，寧願多做也不要少做」）；下列決策 D1–D20 皆附理由，事後可稽核。

## 1. 問題與論點

論點：**以時序 foundation model 的分位數預測當進場規則，比傳統規則好。**

情境：長期投資、只買不賣。每月存入 20,000 元成為現金，規則決定何時把累積的現金全部買進大盤。
「好」的定義：同樣的存入金額與時點，期末資產較高。

### 1.1 事先登錄的主要比較（避免事後挑結果）

主設定：10 年滾動窗口、手續費 0.1425%、當日收盤成交、報酬指數。

| 代號 | 比較 | 意義 |
|---|---|---|
| **H1** | F（Timestral q0.10）對 Q（滾動經驗分位數，252 日，q0.10） | 「智慧預測」是否勝過不用模型的同類規則 |
| **H2** | F 對 G（GARCH-t，q0.10） | 是否勝過經典的統計波動模型 |
| **H3** | F 對 B1（跌破 240 日均線）、B2（從一年高點回檔 10%） | 是否勝過使用者提到的傳統規則 |
| **H4** | F 對 B0（定期定額） | 是否勝過「不擇時」 |
| **H5** | F 對 R（與 F 同觸發頻率的隨機進場） | 進場時點是否有技巧，而不只是「等待」的效果 |

判定：窗口勝率（F 期末資產 > 對手的窗口比例）與期末資產超額（F/對手 − 1）的中位數，兩者同時 > 50%／> 0 才算支持。
其餘設定（q0.05、20 年窗口、全期間、各參數變體、穩健性）皆為次要分析，只用來看主結果是否穩定。

## 2. 資料

| 項目 | 設定 |
|---|---|
| 標的 | 證交所「發行量加權股價報酬指數」（`MFI94U`），2003-01-02 起 |
| 暖機用 | 證交所「發行量加權股價指數」（`MI_5MINS_HIST`），1999-01-05 起，只用於 2003 以前的模型 context 與滾動統計 |
| 拼接 | 2003-01-02 兩者都有：價格指數 × (報酬指數 ÷ 價格指數，當日比值) 接到 2003-01-02 之前 |
| 期間 | 1999-01-05 至抓取日（2026-11-17）的最後一個交易日 |
| 原始資料 | 每月一個原始 JSON，原樣存檔；每次請求記錄網址、時間、HTTP 狀態、SHA256（`data/raw/twse/`） |

## 3. 資金與執行

- 每月第一個交易日存入 20,000 元成為現金；現金不計利息（使用者指定）。
- 每個交易日收盤後判斷規則；條件成立且有現金 → 以當日收盤價買進全部現金，扣手續費。
- 只買不賣；沒有最長等待期（使用者指定）；可買零股（指數部位以單位數計）。
- 期末資產 = 持有單位 × 期末收盤 + 未投入的現金。

## 4. 規則

所有規則在第 t 天只用到 t 收盤（含）以前的資料；分位數下界只用 t−1 以前的資料。

| 代號 | 規則（第 t 天收盤成立就買進全部現金） | 參數 | 主設定 |
|---|---|---|---|
| B0 | 存入當天就買（定期定額） | — | — |
| B1 | 收盤 < N 日均線（含當日） | N ∈ {20, 60, 120, 240} | 240 |
| B2 | 收盤 ≤ (1 − X) × 過去 252 日最高收盤（含當日） | X ∈ {5, 10, 15, 20}% | 10% |
| Q | 當日報酬 < 過去 W 日報酬的經驗 q 分位數（不含當日） | W ∈ {252, 1008}；q ∈ {0.10, 0.05} | W=252、q=0.10 |
| G | 當日報酬 < GARCH(1,1)、Student-t 的條件 q 分位數；每天以過去 1008 日報酬重新估計 | q ∈ {0.10, 0.05} | q=0.10 |
| **F** | 收盤 < Timestral-209M 以過去 C 日收盤預測當日的 q 分位數 | q ∈ {0.10, 0.05}；C ∈ {512, 1024, 2048} | q=0.10、C=1024 |
| R | 每天以機率 p 隨機觸發，p = F 主設定在全期間的觸發率；500 組亂數 | — | — |

- Q、G 以「報酬」表示，等價於「收盤 < 前一日收盤 ×（1 + 報酬分位數）」，與 F 的下界可直接比較。
- F 的預測一律存檔（每天 21 個分位數），規則只讀存檔，預測與回測分開，事後可重算。

## 5. 評估

- **窗口**：從第一個「所有規則都有訊號」的月份起，每月一個起點；長度 10 年、20 年；另加一個「全期間」窗口。
- **每個窗口 × 規則**：期末資產、總存入、XIRR、對 B0 的超額、買進次數、平均現金比例（閒置資金）、
  最大閒置現金、平均每單位成本。
- **彙總**：各規則對 B0、Q、G、B1、B2 的窗口勝率與超額分佈（中位數、平均、P10、P90）。
- **R 對照**：F 的期末資產在 500 組隨機進場中的百分位數。
- **統計解讀**：滾動窗口彼此高度重疊，不是獨立樣本；只報敘述統計，不報 p 值。

### 5.1 預測品質與洩漏檢查（使用者選 a＋b）

- 每天的 F、Q、G 下界：覆蓋率（實際低於 q 下界的比例，理想 = q）與 pinball loss，依年份列出。
- 另列 Timestral-209M 發布（2026-10-14）之後的期間。發布前若明顯比發布後準，是模型看過這段資料的跡象；
  發布後只有約一個月，樣本太少，只能當參考。
- 報告結論一律標註：**Timestral 的預訓練資料未公開，可能包含這段台股資料**。

### 5.2 穩健性（次要）

- 手續費 0 與 0.1425%。
- 隔日收盤成交（第 t 天訊號、第 t+1 天收盤買）。
- 價格指數版本（不含息）：說明除息季的假訊號對結果的影響。

## 7. 決策紀錄

| # | 決策 | 理由 |
|---|---|---|
| D1 | 標的用報酬指數 | 含息、沒有除息缺口；價格指數會在除息季製造假的「下跌」訊號 |
| D2 | 2003 以前只當暖機 | 報酬指數 2003 起才有；投資窗口只用報酬指數，報酬不受拼接影響 |
| D3 | 窗口 10、20 年＋全期間 | 資料約 23.7 年；30、40 年放不下（使用者原本想要，資料不足） |
| D4 | 存入日為每月第一個交易日 | 最常見的定期定額設定，且所有規則同一天拿到錢 |
| D5 | 條件成立就買全部現金 | 「只買不賣」最單純的版本；分批買會多一組自由參數 |
| D6 | 當日收盤成交為主，隔日收盤為穩健性 | 收盤前的價格接近收盤價，指數 ETF 可在收盤競價成交；隔日版本排除這個假設的影響 |
| D7 | 手續費 0.1425%，不計證交稅與管理費 | 只買不賣不會有證交稅；管理費對所有規則相同 |
| D8 | 預測天數 1 天 | 使用者指定 |
| D9 | q0.10 為主，q0.05 次要 | 使用者要兩個都測；主設定只能一個，q0.10 觸發較常，閒置現金較少 |
| D10 | F 預測水準值（收盤），Q、G 預測報酬 | Timestral 直接吃價格序列最自然；Q、G 的經典形式是報酬；兩者都轉成當日下界比較 |
| D11 | Timestral context 1024 日（約 4 年）為主，512、2048 為穩健性 | 1999–2002 的暖機剛好約 1000 日；比較 context 長度影響 |
| D12 | Timestral 用預設推論（含 symmetric averaging） | 官方預設，不調參 |
| D13 | Q 的 W=252 為主 | 一年是最常見的回看長度；1008 對齊 F 的 context |
| D14 | 加 G（GARCH-t） | 使用者要「智慧預測」的價值，對手要包含經典的統計波動模型才公平 |
| D15 | 加 R（隨機進場） | 區分「進場時點的技巧」與「延後投入」本身的效果 |
| D16 | B1 主設定 240 日、B2 主設定 10% | 年線與「修正」的常見定義；其他參數列次要 |
| D17 | 不報 p 值 | 重疊窗口不獨立，p 值會誤導 |
| D18 | 模型與套件版本固定 | Timestral 程式 commit `a534bdb`、權重 revision `9874d25`；`uv.lock` 鎖住其餘套件 |
| D19 | 報告做成單一 HTML，另發成可直接開啟的頁面 | 使用者指定 HTML，並希望一早就能看到 |
| D20 | 全部在雲端 CPU 跑 | 公開資料、模型小（約 0.11 秒／天），不需要 GPU |

## 8. 限制

- **預訓練洩漏**：無法排除；發布後的樣本只有約一個月。
- **只有約 24 年**：10 年窗口約 160 個、20 年約 40 個，彼此重疊，等效樣本少。
- **報酬指數不能直接買**：0050 等 ETF 有追蹤誤差與管理費。
- **只測一個市場、一個模型**：結論不能外推到其他市場或模型。
